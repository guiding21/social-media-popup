# Social Popup - Online Settings

Bu sürüm mevcut popup dosyalarını korur ve tarayıcı üzerinden açılan bir ayar paneli ekler.

## Kullanım
1. Bu klasörü GitHub Pages / Netlify / Cloudflare Pages gibi statik hosting'e yükle.
2. Açılan `index.html` URL'sini Moblin veya OBS Browser Source olarak kullan.
3. Popup içindeki `⚙ Ayarlar` düğmesine bas.
4. Sosyal medya kullanıcı adlarını, scale/hız/süre/offset değerlerini değiştirip Kaydet'e bas.
5. Ayarlar `localStorage` ile kaydedilir.

## Önemli
localStorage ayarları URL'ye göre ve cihaz/tarayıcıya göre tutulur. Yani Moblin'de yaptığın ayarlar bilgisayardaki Chrome'dan ayrı olabilir.

Orijinal dosyalar `original/` klasöründe korunmuştur.


## URL kullanımı

Yayın için:
https://guiding21.github.io/social-media-popup/

Ayarlar için:
https://guiding21.github.io/social-media-popup/settings.html

Yayın URL'sini OBS/Moblin'e eklediğinde ayar paneli görünmez. Ayarları değiştirmek için settings.html adresini aç.
